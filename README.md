### SmartCommerce AI: E-Commerce Backend

[Repository](https://github.com/swapniltalloo/SmartCommerce-AI-Backend) · [API documentation](https://smartcommerce-ai-backend.onrender.com/swagger-ui/index.html)

**Stack:** Java 21, Spring Boot 3, Spring Security, Spring Data JPA, PostgreSQL, Redis, Docker, Swagger/OpenAPI

<img src="https://skillicons.dev/icons?i=java,spring,postgres,redis,docker,maven" alt="SmartCommerce stack" />

A layered backend that models a real-world e-commerce platform.

- Stateless authentication with JWT, a custom validation filter, BCrypt password hashing, and role-based access (USER and ADMIN).
- Product, category, shopping cart, and order management, including order history, status updates, and cancellation.
- Controller, service, and repository layering with DTOs, Jakarta validation, and centralized exception handling.
- Redis caching for frequently requested product queries to reduce database load.
- Personalized product recommendations generated from purchase history through an external LLM API.
- Interactive API documentation and container-based deployment.

### Heart Disease Risk Prediction

[Repository](https://github.com/swapniltalloo/Heart-Stroke-Prediction-by-SWAPNIL)

**Stack:** Python, Pandas, scikit-learn, Joblib, Streamlit

<img src="https://skillicons.dev/icons?i=python,pandas,numpy,sklearn" alt="Heart disease project stack" />

An end-to-end machine learning application that predicts heart disease risk from 11 clinical inputs.

- Compared Logistic Regression, Decision Tree, Random Forest, SVM, and K-Nearest Neighbors; selected KNN based on performance on the dataset.
- Applied one-hot encoding and standard scaling, and persisted the model, scaler, and feature columns with Joblib for consistent inference.
- Built an interactive Streamlit interface returning a High Risk or Low Risk result.
